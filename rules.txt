# MahfilHub Android App - Development Rules

## Project Overview
- **App Name**: MahfilHub
- **Purpose**: Islamic event management platform for public users
- **Target Users**: Public users (non-registered) and Normal registered users (Google/Facebook login)
- **Admin/Maulana**: Managed via separate web platform

## Language Support
- **Supported Languages**: English and Bengali (Bangla)
- **Default Language**: Bengali
- **String Resources**: ALL user-facing text MUST use string resources from strings.xml
- **Translation Files**:
  - English: `res/values/strings.xml`
  - Bengali: `res/values-bn/strings.xml`

## Design System Rules

### Colors
- **ALWAYS** use `MaterialTheme.colorScheme.*` for colors
- **NEVER** hardcode color values in composables
- **Primary Color**: Teal (#00897B for light, #4DB6AC for dark)
- **Secondary Color**: Green (#66BB6A)
- **Tertiary Color**: Orange (#FF9800) for accents and sponsored badges
- **Background**: Cream (#F5F5F0) for light mode, Dark (#121212) for dark mode

### Typography
- **ALWAYS** use `MaterialTheme.typography.*` for text styles
- **NEVER** hardcode font sizes or weights
- **Bengali Font**: System default (TODO: Add Noto Sans Bengali)
- Available styles: displayLarge, displayMedium, displaySmall, headlineLarge, headlineMedium, headlineSmall, titleLarge, titleMedium, titleSmall, bodyLarge, bodyMedium, bodySmall, labelLarge, labelMedium, labelSmall

### Spacing
- **ALWAYS** use `Spacing.*` object for padding and margins
- **NEVER** hardcode dp values
- Available: extraSmall (4dp), small (8dp), medium (16dp), large (24dp), extraLarge (32dp), huge (48dp)

### Corner Radius
- **ALWAYS** use `CornerRadius.*` for rounded corners
- Available: small (4dp), medium (8dp), large (12dp), extraLarge (16dp), round (24dp)

### Elevation
- **ALWAYS** use `Elevation.*` for shadows
- Available: none (0dp), small (1dp), medium (2dp), large (4dp), extraLarge (8dp)

## Component Usage Rules

### Buttons
- **Primary Actions**: Use `PrimaryButton` (e.g., Submit, Login, Continue)
- **Secondary Actions**: Use `SecondaryButton` (e.g., Cancel, Learn More)
- **Tertiary Actions**: Use `TertiaryButton` (e.g., Skip, Back)
- **Compact Spaces**: Use `SmallButton`
- **Loading State**: Set `isLoading = true` on PrimaryButton

### Cards
- **Standard Content**: Use `MahfilCard` (2dp elevation)
- **Featured/Important**: Use `ElevatedMahfilCard` (4dp elevation)
- **Less Important**: Use `OutlinedMahfilCard` (bordered)
- **List Items**: Use `CompactCard`

### Text Fields
- **Standard Input**: Use `MahfilTextField`
- **Password Input**: Use `PasswordTextField` (includes visibility toggle)
- **Search Input**: Use `SearchTextField` (rounded corners)

### Badges
- **Maulana Verification**: Use `VerifiedBadge` with appropriate size
- **Event Status**: Use `StatusBadge` with custom text and colors
- **Notification Count**: Use `CountBadge`
- **Sponsored Events**: Use `SponsoredBadge`

### State Components
- **Loading**: Use `LoadingIndicator` or `FullScreenLoading`
- **No Data**: Use `EmptyState` with title, subtitle, and optional action
- **Errors**: Use `ErrorState` with retry action
- **Dividers**: Use `DividerWithText` for "OR" style separators

## String Resources Rules

### Naming Convention
- **Actions**: `action_*` (e.g., `action_submit`, `action_cancel`)
- **Authentication**: `auth_*` (e.g., `auth_login`, `auth_password`)
- **Input Fields**: `input_*` (e.g., `input_name`, `input_search_hint`)
- **Events**: `event_*` (e.g., `event_title`, `event_location`)
- **Location**: `location_*` (e.g., `location_division`, `location_district`)
- **Reminders**: `reminder_*` (e.g., `reminder_email`, `reminder_alarm`)
- **Maulana**: `maulana_*` (e.g., `maulana_profile`, `maulana_verified`)
- **Status**: `status_*` (e.g., `status_loading`, `status_error`)
- **Empty States**: `empty_*` (e.g., `empty_no_events`)
- **Errors**: `error_*` (e.g., `error_network`, `error_invalid_email`)
- **Navigation**: `nav_*` (e.g., `nav_home`, `nav_events`)
- **Settings**: `settings_*` (e.g., `settings_language`, `settings_theme`)
- **Content Descriptions**: `cd_*` (e.g., `cd_search`, `cd_back`)
- **Onboarding**: `onboarding_*` (e.g., `onboarding_welcome`)
- **Filters**: `filter_*` (e.g., `filter_all`, `filter_today`)
- **Time**: `time_*` (e.g., `time_today`, `time_yesterday`)

### Usage in Composables
```kotlin
// ✅ CORRECT - Using string resources
Text(text = stringResource(R.string.action_submit))

// ❌ WRONG - Hardcoded strings
Text(text = "Submit")
Text(text = "সাবমিট করুন")
```

## Theme Support

### Dark Mode
- **ALWAYS** support both light and dark themes
- **NEVER** hardcode colors that don't adapt to theme
- Test all screens in both themes

### Dynamic Color
- **Disabled** by default for consistent branding
- Can be enabled per user preference (future feature)

## Best Practices

### Compose
1. **State Hoisting**: Lift state to the appropriate level
2. **Reusability**: Create reusable components in `ui/components/`
3. **Preview**: Add `@Preview` for both light and dark themes
4. **Modifiers**: Pass modifiers as parameters for flexibility
5. **Remember**: Use `remember` for state that survives recomposition

### Performance
1. **Lazy Lists**: Use `LazyColumn`/`LazyRow` for scrollable lists
2. **Keys**: Provide stable keys for list items
3. **Derivation**: Use `derivedStateOf` for computed values
4. **Side Effects**: Use appropriate side effect APIs

### Accessibility
1. **Content Descriptions**: Provide for all icons and images
2. **Semantic Properties**: Use semantic modifiers
3. **Touch Targets**: Minimum 48dp for interactive elements
4. **Contrast**: Ensure proper color contrast ratios

- [ ] Support both light and dark themes
- [ ] Add loading, error, and empty states

- **Token Management**: Store securely using EncryptedSharedPreferences

## Event Management

### Event Display
- Show sponsored events after every 3 regular events
- Clearly label sponsored events with `SponsoredBadge`
- Support search by date, location, and Maulana name
- Implement hierarchical location filtering (Division → District → Upazila → Union → Village → Para)

### Reminders
- Support Email reminders
- Support Alarm reminders (local notifications)
- Support Both options
- Request notification permission on Android 13+
